# 政务绿色通道材料受理系统 - 产品需求文档

## 1. 项目概述

### 1.1 项目背景
政务服务中心需要一个高效的材料受理系统，用于窗口人员、事项管理员和办事群众进行材料预审，支持绿色通道快速办理。

### 1.2 目标用户
- **窗口人员**：进行材料受理、状态更新、结果反馈
- **事项管理员**：配置事项类型、材料清单、优先级规则
- **办事群众**：在线预审、查看材料状态、了解办理进度

### 1.3 核心价值
- 提高政务服务效率，减少群众等待时间
- 实现材料容缺受理，优化办事体验
- 优先级智能调度，保障紧急事项及时办理
- 全流程可追溯，数据本地化存储

---

## 2. 功能需求

### 2.1 事项类型管理
- 支持多种政务事项类型配置
- 每个事项可独立配置材料清单
- 事项可配置办理时限

### 2.2 材料清单管理
- **必填材料**：必须上传，缺失则不可受理
- **可容缺材料**：允许后补，有承诺期限
- 材料状态跟踪：已上传、未上传、已容缺、已补件

### 2.3 优先级规则
- 红色优先级：紧急事项，必须显示倒计时
- 橙色优先级：较紧急
- 黄色优先级：普通
- 绿色优先级：可延后

### 2.4 受理状态管理
- **可受理**：所有必填材料齐全
- **绿色通道**：有容缺材料但在承诺期内
- **补件中**：容缺材料超期
- **不可受理**：必填材料缺失

### 2.5 倒计时功能
- 红色优先级事项显示剩余办理时限倒计时
- 容缺材料显示承诺期限倒计时
- 超期自动状态变更

### 2.6 重复提交检测
- 同一申请人重复提交同一事项时提示
- 支持合并受理功能

### 2.7 本地数据存储
- 浏览器 localStorage 持久化存储
- 支持数据导入导出
- 离线可用

---

## 3. 页面结构

### 3.1 材料受理主页
- 顶部导航：用户角色切换（窗口人员/事项管理员/办事群众）
- 左侧：事项类型列表，带优先级标识
- 中间：材料清单区，显示必填/容缺材料状态
- 右侧：受理信息区，显示办理时限、倒计时、受理结果
- 底部：操作按钮区（受理、暂存、取消）

### 3.2 事项配置页（管理员）
- 事项类型CRUD
- 材料清单配置（必填/容缺）
- 优先级规则配置
- 办理时限设置

### 3.3 预审页（办事群众）
- 事项选择
- 材料上传状态展示
- 预审结果反馈

## 4. 业务规则

### 4.1 受理判定规则
```
IF 存在必填材料未上传 → 不可受理
ELSE IF 所有材料齐全 → 可受理
ELSE IF 存在容缺材料在承诺期内 → 绿色通道
ELSE → 补件中
```

### 4.2 优先级显示规则
```
IF 优先级 = 红色 → 显示倒计时 + 红色醒目标识
IF 优先级 = 橙色 → 显示时限 + 橙色标识
IF 优先级 = 黄色 → 显示时限 + 黄色标识
IF 优先级 = 绿色 → 显示时限 + 绿色标识
```

### 4.3 容缺超期规则
```
容缺材料承诺期限到期 → 自动将状态从"绿色通道"转为"补件中"
```

### 4.4 重复提交规则
```
IF 申请人身份证号 + 事项类型 已存在未办结记录 → 提示"该申请人已有同类事项在办，是否合并受理？"
```

## 5. 非功能需求

### 5.1 性能
- 页面加载时间 < 2s
- 本地存储操作响应 < 100ms
- 倒计时更新流畅（1s精度）

### 5.2 兼容性
- 支持主流浏览器（Chrome、Firefox、Safari、Edge）
- 响应式设计，支持桌面端和平板

### 5.3 数据安全
- 所有数据存储在本地浏览器
- 支持数据加密存储（可选）
- 无数据外泄风险

## 6. 测试验证脚本需求

### 6.1 测试场景1：必填材料缺失验证
1. 进入受理页面
2. 取消一项必填材料的"已上传"状态
3. 验证"受理"按钮变为禁用状态
4. 验证状态显示为"不可受理"

### 6.2 测试场景2：容缺材料超期验证
1. 进入受理页面
2. 将一个容缺材料的承诺期限调整为已过期
3. 验证受理状态从"绿色通道"变为"补件中"
4. 验证倒计时显示过期标识
